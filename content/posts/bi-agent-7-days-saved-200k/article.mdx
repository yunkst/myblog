## 背景

公司 BI 跑在 FineBI 个人版 + 腾讯云 MapReduce + ClickHouse。搭建人离职后，MapReduce 几乎每天 OOM，运营天天催我修。

每月 MapReduce 订阅 + 扩容至少 <Counter from={0} to={8000} suffix=" 元" label="每月固定开支" />，再加扩容就是几千元。这对一个要辞退保洁阿姨的小公司，是"最后一根稻草"。

## 三步走

### 1. 重构数仓：Doris + Flink CDC

放弃 Hadoop 生态，组件砍到 2 个，带来两个史诗级好处：

- **半实时同步**：运营不用等第二天才能看销售数据
- **JOIN 效率**：原本的 backfill 脚本大量被消化

### 2. 放弃 FineBI

- 企业版：一年十万 → 告辞
- Metabase / Rill / Evidence：需要专门招一个数据同事，迁移成本一样高
- **FineBI 看板搭建人也离职了，谁来重搭？**

### 3. 自研 BI-Agent

让 AI 写看板代码，我在 7 天里完成从零到上线：

- **portal / dashboard-app**：React 前端
- **bi-agent**：内嵌 LLM，做看板的创建和修改
- **bi-checker**：用 tsc 检查 Agent 产出的看板代码质量
- **bi-data-layer**：SQL 安全代理，唯一取数入口（避免前端直连数据库）

## 关键设计

1. **看板即代码**：看板是 React 组件，存 Git
2. **git worktree 预览**：Agent 在 worktree 里编辑，不污染主分支
3. **SQL 安全代理**：AST 校验 + RLS 织入 + 表/角色白名单，五层防御
4. **ReAct 双层循环**：内层 ≤8 轮执行，外层 ≤2 轮验证修复门
