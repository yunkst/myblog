# 原理图设计契约（ArchDiagram）

> 本文是博客全部原理图（`content/posts/<slug>/diagrams.ts`，经 `ArchDiagram` 渲染）的设计规则。
> 每条规则都有对应的自动化校验（`ArchDiagram.test.tsx`）或渲染实现兜底——规则不是建议，是契约。
> 方法论参考 archify 项目的 DESIGN.md，按本博客的浅色/深色双语境做了适配。

## 1. 语义色规则

颜色只为含义服务。节点按 `kind` 固定一个语义色（描边 + 预混白的 pastel 淡底），
不加无含义的点缀色：

| kind       | 含义       | 描边      | 淡底      |
| ---------- | ---------- | --------- | --------- |
| `key`      | 核心       | `#0E6E5C` | `#EDF5F2` |
| `be`       | 服务       | `#3B5BDB` | `#EEF1FC` |
| `db`       | 存储       | `#7048E8` | `#F1EDFB` |
| `mq`       | 队列       | `#E8890C` | `#FBF3E6` |
| `external` | 外部       | `#5C7C8A` | `#EFF3F5` |

- 淡底必须是不透明 pastel：原理图同时出现在深色舞台（`.stage`）和浅色平铺页两个语境，
  半透明淡底在深色上会脏。
- `key` 节点描边加粗（1.8px，其余 1.2px）保留层级，但同一含义永远同一色。
- 单一事实源：`ARCH_KIND_STYLE`。新增 kind 必须先加色板再画图。

## 2. 图例自动规则

图例不需要手写，由图里实际出现的 kind 自动生成；图里有虚线边时自动追加
「次要 / 复用」约定项。

- 位置默认左上角 `(12,12)`；与图元素相撞时在该图数据里显式给 `legendAt` 逃生口。
- 图例矩形（`legendRect`）与渲染几何严格一致，测试断言它不与任何节点 / bound /
  bound 贴纸相撞——撞了就是测试失败，不允许「看起来还行」。

## 3. 主路径优先规则

边分三级，读者视线应该被主路径牵着走：

- `emph`：主路径，语义绿 `#0E6E5C` 加粗（1.8px）。一张图的主路径只能有一条语义主线，
  别把无关边标 emph。
- `dash`：次要 / 复用路径，灰 `#8FA3AB` 虚线。虚线必须是次要的——主路径不许用虚线。
- 普通：墨色 `#55665F` 细线。

## 4. 文字可辨识下限规则

节点文字允许收缩，但收缩有下限，跌破下限不允许放任溢出：

- label：优先 11.5px，下限 9px；sub：优先 9.5px，下限 8px。
- 跌破下限仍装不下 = 图数据错误（加宽节点或缩短文案），
  由 `nodeTextFitProblems` 测试拦截，不靠肉眼发现。
- 文字宽度估算区分全半角：CJK 1.05 单位 / 其余 0.65 单位（`textUnits`）。

## 5. 避让完备规则

任何贴纸类元素（bound 图例贴纸、边标签、自动图例）都不允许压住别的元素，
**边线本身也不得穿越第三方节点**（2026-09-01 增补——旧假设「锚点在边框上 ⇒
path 只存在于两节点间隙」只对无 via 直连边成立，带 via 的绕行边可穿透节点，
实锤：figArchitecture e7 的 x=680 竖线穿过 policy 节点）：

- 障碍集 = 节点 + bound 图例贴纸 + 已放置的边标签 + 自动图例。
- 边线：`edgeNodeCrossings` 对每条边的折线段做第三方节点相交检测
  （端点节点锚点在边框上合法；纯贴边 graze 不算穿越，矩形内缩 1px 判定），
  测试断言为空——via 绕行时必须走「行间/列间通道」，不允许偷懒穿节点。
- 边标签由 `edgeLabelPos` 在折线 50%/35%/65% 处取点、法线两侧 ±12~±56 试探，
  首个不碰障碍的位置胜出；全撞回退中点位（白底贴纸兜底），顽固边用 `labelDx/labelDy` 微调。
- 测试对全部图数据复现渲染预排，断言零碰撞。

## 6. 数据光点规则（2026-09-01 v3.3 修订）

> 本规则替代原「动效有界规则」中的脉冲式单次流动——用户裁定：
> 「走一遍即消失的虚线」不够直观，改为持续可见的数据光点。

- **每条边一个光点**，SMIL `animateMotion` 沿边匀速常流（统一 110 单位/秒，
  时长 = 边长 / 速度）——持续表达「数据沿线路流动」，读者随时看图都能读到流向。
- **颜色 = 出发节点的语义色**：不同线路自然不同色，且颜色仍然只为含义服务，
  不新增无含义的调色板。
- 光点小而低存在（r 2.5 + 同色柔光晕）：是流向提示，不是视觉主角；
  静帧信息不依赖它（边线、箭头、标签都在）。
- **交互联动**：聚焦 / 悬停时，相关边的光点放大到 r 3.4（与淡出相反的强调方向），
  无关边的光点随边一起淡出到 0.28。
- 揭示动画里光点最后淡入；`prefers-reduced-motion` 下光点整体隐藏（CSS），
  其余规则（揭示直出终态、静帧不丢信息）不变。

## 7. 交互不编造拓扑规则

原理图的交互只揭示作者（图数据）已经声明的关系，不推断任何运行时影响：

- **悬停**节点：该节点 + 一度邻居 + 相连边保持强显示，无关节点/边**直接隐藏**
  （opacity 0 + `pointer-events: none` 防幽灵悬停与闪烁）；移开即恢复。
- **点击**节点：锁定聚焦，沿有向边 BFS 出完整上游（服务蓝 `#3B5BDB`）/ 下游
  （核心绿 `#0E6E5C`）子图，无关拓扑淡出；回环里双向可达的边取下游绿。
  再点该节点、点空白、或按 Esc 退出。
- 点击冲突约定：点节点 = 聚焦（stopPropagation）；点空白 = 重播动画；
  锁定态下点空白只退出聚焦、不重播。
- 聚焦时出现状态条（聚焦对象 + 颜色约定 + 退出方式），不新增常驻面板。
- 淡出是状态不是动效：`prefers-reduced-motion` 下同样可用。
- 可达性纯函数（`reachableSets` / `adjacentSets`）有单测实锤，聚焦行为有渲染测试。

---

### 新增一张原理图的 checklist

1. 在对应文章的 `content/posts/<slug>/diagrams.ts` 里写 `nodes/edges/bounds`，kind 只能取色板里的五种。
2. 标 emph（主路径）与 dash（次要路径），遵守第 3 条。
3. 跑 `vitest run src/components/blog-anim/ArchDiagram.test.tsx`：
   文字下限、标签避让、**边线穿节点**、图例碰撞全部自动校验。
4. 图例撞了 → 给 `legendAt`；文字跌破下限 → 加宽节点或缩短文案；标签避让不下 → `labelDx/labelDy`；
   边线穿节点 → via 改走行间/列间通道（参考 figArchitecture e7 的修法）。
