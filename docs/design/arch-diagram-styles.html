架构图风格 · 三方案

同一张图（读多写少 + 缓存 + 异步写），三种视觉处理。画法吸收 archify：语义类型节点、sigil 图标、遮罩式连线标签、边界区域、要点卡。

方案 A

工程图纸 · 纸白（主页同款）

类型不靠色相区分，靠 sigil 图标 + 边框记号；全图只有墨线 + 图纸青。与首页视觉完全连续，整体最克制。

读路径

  • 网关按 key 哈希分片到 3 个读副本
  • redis 前置，ttl 30s，命中率 96%

写路径

  • 写入先进队列，削峰
  • 写服务批量落库，失败重试 3 次

一致性

  • 缓存双删 + 版本号防旧值回填
  • 压测峰值 4200 QPS 下 P99 < 80ms

archify blueprint 同源：深青图纸 + 亮青描边 + 高亮强调色。动画对比度最好，但页面其余部分需要跟着换深色或做局部深色区。

语义浅色 · 类型配色

archify classic 浅色同源：每类节点一种描边色（前端青/后端绿/数据紫/队列橙）。信息密度最高、一眼分层，但颜色最多，和纸白主页的克制气质有张力。

我的建议：A 为主，借 B 的强调逻辑

理由一：求职博客的核心是"讲清楚"，A 的单色墨线最像"你亲手画的图"，可信度高于彩色模板感。

理由二：动画只在 A 里做"图纸青描边 + 节点装配"就足够醒目（下面点 FAQ 可预览），不需要整图换深色。

理由三：若某篇文章确实想用深色蓝图（B），可以做成文章内的独立样式——组件层面支持，不影响全站统一。
